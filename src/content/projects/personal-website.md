This site is a personal publishing surface for projects, notes, and experiments. The project pages are powered by Markdown content collections so new entries can be added without creating a new Astro route each time.

The current version focuses on a reusable layout system, class-based theming, content-driven project pages, and an immersive project detail view that can show a live site beside the write-up.

Future work will likely include richer filtering, blog posts that reuse the same prose component, and stronger metadata for project links and case studies.
